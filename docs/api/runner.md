# runner


## `evaluate_record`

逐样本评测并校验音频根目录、采样率和形状。缓存身份覆盖规范记录与实际输入文件字节；文件变化会触发重新计算。

## `evaluate_dataset`

按清单顺序评测，支持从完整模式的部分结果续跑。清单内容改变会拒绝旧运行；仅重排记录时可按 ID 复用结果。

## `aggregate_results`

同时报告语料级 WER 与逐条平均 WER/CER，避免混淆不同加权方式。音频指标采用固定种子的 bootstrap 区间，空集合不虚构均值。

## `report_json`

JSON 报告保留每条输入身份摘要、指标与聚合结果，使用严格有限数值和稳定字段顺序。续跑应使用运行检查点，报告另含 summary 字段。

## `report_csv`

输出适合逐样本比较的 CSV，正确处理 Unicode、逗号和引号。没有音频的样本用空单元格表示缺失指标，不用零值替代。
