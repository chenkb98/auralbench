# statistics


## `finite_values`

统一校验统计观测值，拒绝空样本、非有限值和隐式字符串/布尔转换。返回独立 float64 数组。

## `mean`

缩放后求算术均值，降低多个巨大有限数相加造成溢出的风险。空样本不会被当成零均值。

## `median`

报告样本中位数，偶数样本使用中间两值的平均。计算保留原始观测顺序，并对极大数进行缩放。

## `quantile`

显式使用 NumPy 的 linear 分位数定义，避免库默认行为变化造成报告漂移。概率端点分别对应样本最小值与最大值。

## `trimmed_mean`

从两侧各删除 floor(n×比例) 个观测后取均值。明确报告截尾比例，不把删去异常值后的结果冒充未经处理的总体均值。

## `bootstrap_mean`

对独立观测执行可复现的百分位 bootstrap，返回样本数、种子和置信水平。相关录音或同一说话人的多个片段应先按合适单位聚合。
