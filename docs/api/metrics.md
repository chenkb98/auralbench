# metrics


## `si_sdr`

去均值后对参考信号投影，计算尺度不变 SDR，并将结果限制在有限 dB 范围。完全静音配对返回上限；仅一侧静音返回下限。

## `log_spectral_distance`

以固定谱幅下限计算 dB 频谱差的 RMS。它是简单信号诊断，不称为 FAD、PESQ 或 STOI，也不代替听感评测。

## `duration_error`

输出时长减去参考时长，单位秒，负值表示输出较短。允许比较不同采样率与声道数，不按文件字节数估计时长。

## `score_transcript`

同时报告 WER、CER 和完整词级错误计数，使总体错误率可追溯到插入、删除与替换，而不是只保留一个比例。

## `score_audio`

汇总配对音频的信号诊断，要求采样率、形状与对齐已由调用者明确处理。不会自动裁剪较长输出来改善结果。
